# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [1.3.0] - 2026-08-23

### Changed

- Cardio is now a text section.
- Warmup, Cardio, Cooldown, and Notes use plain read mode with explicit edit mode.
- Legacy Cardio lists migrate safely.
- Plan export schema v2 preserves compatibility with v1 imports.
- Improved Plan section hierarchy and mobile readability.

## [1.2.0] - 2026-08-23

### Changed

- Splash animation is now sub-second.
- Redesigned Body around a chart-first mobile hierarchy, including Body Stats with stored height/age and BMI.
- Added Body export/CSV age compatibility.
- Normalized compact, title-only mode headers and aligned HIIT/Stopwatch headers.

## [1.1.0] - 2026-08-23

First tagged release.

### Changed

- Splash animation runs 30% faster.
